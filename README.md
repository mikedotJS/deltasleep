# deltasleep

Sleep-debt tracker for iOS — a 14-night rolling debt figure, surfaced primarily as a
Home Screen widget, backed by Apple Health sleep data.

The full phased plan, design rationale, and open decisions live in
[`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md). The design source of
truth is [`docs/design/mockup-liquid-glass-v02.html`](docs/design/mockup-liquid-glass-v02.html).

## Getting set up

This project's Xcode project is generated, not committed. You'll need a Mac with
Xcode 26+ installed.

```sh
brew install xcodegen
xcodegen generate
open DeltaSleep.xcodeproj
```

Re-run `xcodegen generate` any time `project.yml` changes.

## Structure

```
DeltaSleep.xcodeproj      generated by XcodeGen, gitignored
├─ App/DeltaSleep          app target
├─ Widget/DeltaSleepWidget widget extension — never touches HealthKit directly
└─ Packages/
   ├─ SleepDebtCore        pure Swift domain model + debt engine (no HealthKit, no UI)
   ├─ HealthSleepSource    HealthKit → [Night], behind a protocol
   ├─ SnapshotStore        App Group cache + refresh orchestration
   └─ GlassKit             design tokens + glass surfaces + shared components
```

Each package builds and tests independently:

```sh
swift test --package-path Packages/SleepDebtCore
```

## Status

Scaffolding only (P0 — see [issue #3](https://github.com/mikedotJS/deltasleep/issues/3)).
The four packages are empty placeholders; the app and widget are blank shells that
should build and appear in the simulator's widget gallery. Real implementation starts
at P1 ([issue #4](https://github.com/mikedotJS/deltasleep/issues/4)).

This scaffold was authored without access to Xcode or a Swift toolchain (built in a
Linux container with no path to install one). It has not been opened in Xcode or run
through `xcodebuild` locally — [CI](.github/workflows/ci.yml), which runs on a
`macos-latest` runner, is the first real build/test verification. Check its status
before trusting that `xcodegen generate` and the build succeed as written.

## Bundle identifiers

`project.yml` uses `com.mikedotjs.deltasleep` and the `group.com.mikedotjs.deltasleep`
App Group as placeholders. Update both to match your actual Apple Developer Team
before provisioning or archiving.
